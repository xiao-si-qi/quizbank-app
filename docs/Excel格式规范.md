# Excel 格式规范

App 的解析器是**容错**的：列顺序随意、多余列忽略、表头别名可识别、全角半角与混用标点都能处理。
下面的「标准格式」只是最省事的写法。

## 一、题库列表（目录表）

一行一个题库。

| 列 | 必需 | 别名（都能识别） |
|---|---|---|
| 题库ID | 否 | `id`、`编号`、`标识` |
| 题库名称 | 建议 | `名称`、`题库`、`标题`、`名字`、`name`、`title` |
| 分类 | 否 | `类别`、`科目`、`题库分类`、`category`、`group` |
| 描述 | 否 | `简介`、`说明`、`介绍`、`备注`、`description`、`desc`、`remark`、`memo` |
| 文件地址 | **必需** | `地址`、`路径`、`链接`、`文件`、`下载地址`、`题库地址`、`url`、`path`、`file`、`link` |
| 题目数量 | 否 | `题数`、`题目数`、`数量`、`总数`、`count`、`total` |
| 版本 | 否 | `版本号`、`version` |
| 标签 | 否 | `tags`、`tag` |

补充规则：

- 找不到「名称」列时，用文件名兜底（`/题库/网络基础.xlsx` → 「网络基础」）。
- 「文件地址」列的表头完全不认识时，会按**内容特征**猜（含 `/`、以 `.xlsx/.csv` 结尾、以 `http` 开头）。
- 地址重复的行会自动去重。
- 含 `/` 或 `http` 的行不会被误判成表头，所以前面多加几行说明文字也没问题。

### 文件地址写法的三种形式

| 写法 | 例子 | 说明 |
|---|---|---|
| alist 路径 | `/题库/网络.xlsx` | 推荐，换域名不用改表 |
| alist 直链 | `https://pan.example.com/d/题库/网络.xlsx` | 直接下载 |
| 网页链接 | `https://pan.example.com/题库/网络.xlsx` | 会被自动识别并转成 alist 路径 |

## 一之二、考试组卷配置（可选列）

点卡片上的「考试」抽出来的卷子长什么样，由题库列表里的这几列决定。**全都可以不填**。

| 列名 | 别名 | 说明 |
|---|---|---|
| 组卷 | 试卷结构、组卷规则 | 最精确的写法，格式 `题型:题数*每题分值`，多段用 `;` 隔开 |
| 考试题数 | 试卷题数 | 只写总题数，各题型按题库里的题量比例分配 |
| 单选题分 | 单选分值 | 每道单选题多少分 |
| 多选题分 | 多选分值 | |
| 判断题分 | 判断分值 | |
| 填空题分 | 填空分值 | |
| 简答题分 | 简答分值 | |

**组卷列的例子**

```
单选:20*2;多选:5*4;判断:10*2;填空:5*2;简答:1*10
```

意思就是：20 道单选每题 2 分、5 道多选每题 4 分、10 道判断每题 2 分、
5 道填空每题 2 分、1 道简答 10 分 —— 共 41 题、满分正好 **100 分**。

写法也兼容 `单选*20*2`（题型*题数*分值）。

**三种配置方式的优先级**

1. 填了 **组卷** → 严格按它抽题、按它算分；
2. 只填了 **考试题数** → 抽那么多题，各题型按题量占比分配；
3. 都没填 → 用默认分值（单选 1、多选 2、判断 1、填空 2、简答 5），
   按题型轮转抽题，把满分**凑到 100 分**。

**成绩怎么算**

- 试卷满分 = 抽中所有题的分值之和（配置合理时正好 100）
- 原始得分 = 答对题目的分值之和
- 界面上分数一律按**百分制**显示：`得分 ÷ 满分 × 100`，所以题库题量少、凑不满 100 分时，
  成绩依然是一百分制（标题会显示实际满分）。

## 二、题库文件

| 列 | 必需 | 别名 |
|---|---|---|
| 题号 | 否 | `序号`、`编号`、`no`、`index`、`id` |
| 题型 | 否 | `类型`、`题目类型`、`试题类型`、`type` |
| 题干 | **必需** | `题目`、`试题`、`问题`、`题目内容`、`内容`、`question`、`stem`、`title` |
| 选项A…选项F | 否 | `A`、`选项1`、`OptionC`、`选项A内容`、`answer_A`、`答案A` … |
| 选项（合一） | 否 | `备选项`、`选项列表`、`options`、`choices` |
| 答案 | 建议 | `正确答案`、`参考答案`、`标准答案`、`answer`、`key` |
| 解析 | 否 | `答案解析`、`试题解析`、`解答`、`说明`、`explain`、`analysis` |
| 难度 | 否 | `难度系数`、`难易度`、`difficulty`、`level`（1–5；填 0.3 这种小数会换算） |
| 章节 | 否 | `科目`、`知识点`、`分类`、`考察内容`、`examination_scope`、`chapter`、`section` |
| 标签 | 否 | `标记`、`考点`、`参考资料`、`reference`、`重要级别`、`important`、`tags`、`tag`（**可以有多列，会合并**） |
| 分值 | 否 | `分数`、`得分`、`score`、`point` |

### 题型

`单选题` / `多选题` / `判断题` / `填空题` / `简答题`，
也认 `单选/多选/判断/填空/简答/不定项/主观/单项` 以及 `single/multiple/judge/blank/essay`。

还兼容旧版题库的数字编码：**`1`=单选、`2`=多选、`3`=判断、`4`=问答**。

**不写题型列也能用**，App 会推断：

- 题干前有 `【单选题】` 这类前缀 → 用前缀里的题型，前缀会自动从题干里去掉
- 有选项 + 答案是单个字母 → 单选
- 有选项 + 答案是多个字母 → 多选
- 没有选项 + 答案是 `对/错/√/×/T/F/是/否` → 判断
- 没有选项 + 题干含「简述/论述/说明/为什么…」或答案较长 → 简答
- 其余 → 填空

工作表名也能当题型：表名叫「判断题」，整张表都按判断题导入。
一个文件多个工作表会合并导入。

### 选项的三种写法

```
写法一（推荐，分列）
选项A=北京  选项B=上海  选项C=广州  选项D=深圳

写法二（合一列，单元格内换行）
选项 = "A. 北京
B. 上海
C. 广州"

写法三（直接写在题干里，会自动拆开）
题干 = "下列哪个是首都？
A. 北京
B. 上海
C. 广州"
```

### 答案的写法

| 题型 | 写法 |
|---|---|
| 单选 | `A`，`a`，`A.` |
| 多选 | `ABD`、`A,B,D`、`A、B、D`、`A B D`、`A；B；D` |
| 判断 | `对`、`正确`、`√`、`是`、`T`、`TRUE`、`1`；`错`、`错误`、`×`、`否`、`F`、`0` |
| 填空 | 多个空用 `\|` 分隔：`北京\|上海` |
| 简答 | 参考答案文本（练习时由用户自评对错） |

单选题的答案也可以直接写**选项文本**（写「北京」而不是「A」），App 会自动对应到选项。

## 三、图片

题干、选项、解析都可以混排图片，三种写法：

```
![电路图](images/circuit1.png)
<img src="images/circuit2.png">
images/circuit3.png        ← 单独成行时
```

- **相对路径相对于题库文件所在目录**。
  题库在 `/题库/网络/网络.xlsx`，写 `images/a.png` → 实际读取 `/题库/网络/images/a.png`。
  也支持 `./` 与 `../`。
- 也可以写完整网址（`https://…`）。
- 图片通过 alist 的 API 下载，**私有网盘也能显示**；下载后会缓存到手机，离线可看。
- 「设置 → 图片」里可以关掉「下载题库时顺便缓存图片」，改成用时再取。

## 四、兼容旧版题库 App 的格式

如果你之前用过旧版题库 App，它的 CSV 可以**直接拿来用**，表头长这样：

```
id,num,questionType,question,answer_A,answer_B,answer_C,answer_D,answer_E,
right_answer,examination_scope,reference,important
```

对应关系：

| 旧版列 | 新版当成 |
|---|---|
| `question` | 题干 |
| `questionType`（`1/2/3/4`） | 题型（单选/多选/判断/简答） |
| `answer_A`…`answer_E` | 选项 A–E |
| `right_answer` | 答案（判断题的 `1`/`0` 会转成对/错） |
| `examination_scope` | 章节 |
| `reference`、`important` | 标签（参考资料、重要级别） |
| `id`、`num` | 忽略（新版自己排序） |

旧版题库列表（`item_list.csv`，列为 `id,name,url,fileName`）也能被当作题库列表读取，
`url` 会被识别成文件地址、`name` 是题库名称。

> 顺带修掉一个隐患：以前 `answer_A` 会被「答案」列抢走（因为表头里含 `answer`），
> 结果正确答案变成「选项 A 的文本」。现在选项列的识别优先级更高，不会再有这种静默错误。

## 五、CSV

`.csv` 与 `.xlsx` 同等对待：

- 自动识别编码：UTF-8（含 BOM）、UTF-16、GB18030/GBK
- 自动识别分隔符：逗号、制表符、分号、竖线
- 支持 RFC4180 引号规则（字段内含逗号、换行、双引号）

## 六、不支持

- 旧版二进制 `.xls`（Android 端无法解析）→ 请在 Excel/WPS 里另存为 `.xlsx`
- `.xlsb`、带密码的加密工作簿
- 单元格内嵌的**浮动图片**（Excel 的 drawing 层）→ 请改成写图片链接，这也是本 App 推荐的用法
