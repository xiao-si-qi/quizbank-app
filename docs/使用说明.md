# 使用说明

面向使用者，不需要懂技术。

## 1. 安装

安装 `题库-v1.0.0-debug.apk`。首次打开如果提示「未知来源应用」，在系统设置里允许一次即可。

## 2. 打开就能用（不需要任何设置）

**第一次打开 App，它会自动去获取公开题库并下载好**，你只需要等几秒钟：

```
正在准备题库
正在获取在线题库…
正在下载「计算机基础」 1/2
正在下载「生活常识」 2/2
```

下载完，首页就会出现题库卡片，直接点「顺序练习」就能开始做题。

如果当时没网、或者在线题库临时打不开，App 会**自动载入一份内置示例题库**，
保证你打开就能练（首页会有一行提示，网络恢复后点「重试」即可获取在线题库）。

> 不想用内置题库兜底？在「设置 → 内置题库」里关掉即可。

## 3. 想看更多题库？登录一下

首页顶部会有一条「登录后可获取更多题库」的提示，点「去登录」。

登录页只有三个输入框：

| 字段 | 说明 |
|---|---|
| 服务器地址 | 已经填好了默认地址，**一般不用改**（除非用你自己的 alist） |
| 用户名 | 向题库管理员要 |
| 密码 | 同上 |

登录成功后：

- 会自动切换到你账号下有权限的**全部**题库（不只是公开的）
- 练习成绩会自动保存到你自己名下的目录，换手机也不丢
- 如果是老师/管理员账号，成绩页还能看到所有人的成绩与逐题作答记录

登录状态可以在首页右上角头像、或「设置 → 账号」里查看和退出。

## 4. 练习

首页每个题库卡片上：

- **顺序练习**：从上次停下的地方继续
- **随机练习**：打乱顺序
- 卡片右上 **⋮**：继续上次 / 错题练习 / 收藏练习 / 查看统计 / 重新下载更新 / 删除题库

练习界面：

- **左右滑动**即可切上一题/下一题（也可以用底部的「上一题 / 下一题」按钮）
- 选择题点选项即判分；多选题选完点「提交答案」
- 填空题输入答案，多个空用 `|` 分隔
- 简答题点「看答案」后自己点「我答对了 / 我答错了」
- 右上角 ♥ 收藏本题
- **右下角的「题目清单 x/y」**点开就是答题卡，能看哪些题答过、哪些没答，点题号直接跳过去
- 答完最后一题自动交卷，给出得分

题目里的图片会自动下载并缓存在手机上，**离线也能看图**。

> 注意：**普通练习只帮你记错题和阅读进度，不会生成成绩、也不会往上上传。**
> 想要分数、想留考试记录，请点卡片上的「考试」。

## 5. 考试模式（只有它会记成绩）

在题库卡片上点**「考试」**按钮（和「顺序练习」「随机练习」并排）。

和练习不同的是：

| | 普通练习 | 考试模式 |
|---|---|---|
| 答完一题就判分、看解析 | ✅ 立即显示 | ❌ 全程不显示，交卷后统一判 |
| 生成成绩 | ❌ 只记错题 | ✅ 有总分、得分、用时 |
| 上传到 alist | ❌ 不上传 | ✅ 可上传，管理员能看到 |
| 留下考试记录 | ❌ | ✅ 可随时回顾这次抽到的每道题 |

考试页的操作和练习一样：**左右滑动切题**，右下角「题目清单」看答题卡，
区别只是答题过程中不判分、不显示答案。

考试怎么组卷、每类题多少分，由管理员在**题库列表 Excel** 里配（见
[Excel格式规范.md](Excel格式规范.md)）。没配的话：默认单选 1 分、多选 2 分、
判断 1 分、填空 2 分、简答 5 分，自动凑满 **100 分**。

交卷后你会看到：

- **百分制得分**（满分按 100 算）和原始分（例如 `82 / 100 分`）
- 答对几题、答错几题、用了多久
- **逐题回顾**：点开任意一题，能看到题干、选项、我的作答、正确答案和解析
- 主观题（简答题）交卷后由你自己点「我答对了 / 我答错了」，改完分数会实时更新

## 6. 考试记录与上传

首页 **⋮ → 考试记录与上传**。标签页会**按你的身份显示**，能看几个就显示几个：

| 标签页 | 什么时候出现 | 内容 |
|---|---|---|
| **本机记录** | 总是有 | 这台手机上的所有考试，可以单条上传，也可以「全部上传」 |
| **云端记录** | **登录之后** | 从 alist 读回**你自己**上传过的考试记录，换手机也不丢 |
| **全部用户** | **只有 alist 管理员** | 按用户分组，点进去能看到每个人每次考试的得分，再点某一条就能回顾那次考试抽到的每一道题 |

> 没登录时只会看到「本机记录」；普通账号登录后多出「云端记录」；管理员才看得到「全部用户」。

每条记录是一个独立的 JSON 文件，存在 alist 的「成绩根目录/你的用户名/」里，
一次考试一个文件，所以多台设备同时上传也不会互相覆盖。

成绩根目录是所有人共用的（默认 `/题库/成绩`），App 会自动在里面按用户名建子目录——
这样管理员打开「全部用户」就能一次看到所有人的成绩。

## 7. 设置里都有什么

绝大多数设置都不用动（都有默认值）。常用的几个：

| 设置项 | 说明 |
|---|---|
| 账号 | 服务器地址、登录/退出。**不需要手填 token** |
| 题库列表 | 已填好默认值；登录后自动换成完整清单。改过之后可以点「恢复自动设置」 |
| 考试记录上传 | 这是所有人共用的成绩根目录，登录后自动填好；App 会在它下面按用户名建子目录。可开「考试结束后自动上传」（普通练习不上传） |
| 内置题库 | 在线题库打不开时是否用内置示例题库兜底 |
| 图片 | 是否随题库一起缓存图片、只在 Wi-Fi 下缓存、清空缓存 |
| 练习 | 打乱题目/选项、答对自动移出错题、答完立即显示解析 |
| 显示 | 主题（跟随系统/浅色/深色）、字体大小 |
| 模板与数据 | 导出 Excel 模板、导入本地 Excel、清空答题记录 |

## 8. 常见问题

**打开 App 一直停在「正在获取在线题库」**
网络不通，或者服务器暂时不可用。等一会儿点「重试」；期间可以先用内置题库。
如果你用的是自己的 alist，去「设置 → 账号」把服务器地址改成你的。

**登录提示「登录失败」**
用户名或密码不对；或者服务器地址被改错了（点「设置 → 账号 → 测试连接」确认能连上）。

**题库里图片显示「图片没能加载」**
点一下「重试」。一直失败通常是 Excel 里的图片路径写错了——
相对路径是相对于**题库文件所在目录**的，可以对照 [Excel格式规范.md](Excel格式规范.md) 检查。

**导入自己的 Excel 时说「没有识别出任何题目」**
表头里至少要有一列叫「题干」（或「题目」「试题」）。最省事的做法：
「设置 → 模板与数据 → 导出题库模板」，照着模板填。

**CSV 乱码**
不会。App 会自动识别 UTF-8 与 GBK。

**旧版 .xls 打不开**
安卓端没法直接解析二进制 .xls。请在 Excel/WPS 里「另存为」→ `Excel 工作簿 (*.xlsx)`。

**为什么练习完没有成绩？**
这是故意的。普通练习只记错题，避免刷题时产生一堆没意义的记录；
要成绩就点题库卡片上的「考试」按钮。

**考试满分不是 100 分？**
考试成绩一律按百分制显示。如果你在题库里只抽到 15 分的题（题库题量太少凑不满 100），
标题会显示实际满分，得分仍然按 `得分 ÷ 满分 × 100` 折算。

**重新下载题库会丢错题吗**
不会。重新导入会按题干匹配，把收藏、错题、答题记录尽量挂到新题目上。

## 9. 数据存在哪

- 题库、题目、错题、收藏、成绩：App 私有目录里的 `quizbank.db`
- 图片缓存：App 私有目录 `images/`（设置里可清空，默认上限 200MB）

卸载 App 会一起删除。要长期保存的成绩记得登录后上传到 alist。
